# xliffkit

xliffkit は、**CATツール が生成する xliff ファイルを実務で安全に扱うための Python ライブラリ**。

名前は xliffkit だが、  
**対応範囲は意図的に mqXLIFF に限定**している。

XLIFF 全体対応や他ツール（Trados 等）の方言対応はスコープ外。  
必要になったら dialect として切り出す前提。

---

## 目的

- xliffを **機械処理しやすい中間表現に落とす**
- タグやセグメントの **見た目・構造の歪みを正規化する**
- 不適切なセグメント分割を **ルールベースで分割・再統合する**
- CLI やアプリに依存しない **純ライブラリ**として提供する

このライブラリは「翻訳をする」ものではない。  
**xliff を壊さずに触るための道具箱**。

---

## 対応フォーマット

- 対応：**memoQ 生成 XLIFF（mqXLIFF）**
- 非対応：
  - Trados 由来 XLIFF
  - generic XLIFF の完全実装
  - XLIFF 仕様全体の網羅

mqXLIFF 特有の仕様・癖は `dialects/mqxliff.py` に隔離する方針。

---

## 基本思想

- ライブラリは **状態を持たない**
- 設定・ログ・CLI は上位レイヤーの責務
- xliff XML を直接触る箇所は最小限
- すべての処理は **中間表現（models）を経由**する

---

## ディレクトリ構成

```text
xliffkit/
├─ core/          # parser / serializer / 中間モデル
├─ dialects/      # mqXLIFF 固有仕様の隔離
├─ io/            # yaml などへの入出力
├─ normalize/     # タグ・テキスト正規化
├─ segment/       # 分割・統合ロジック
├─ utils/
└─ exceptions.py
````

---

## 主な機能

以下機能の詳細は [examples](xliffkit/docs/examples.md) にて。

### 1. タグ正規化

* 視認性の低い inline tag を適切な構造に修正

  * ph 化された b/i 等を bpt/ept に戻すなど

* 意味は変えず、構造だけを整える

---

### 2. セグメント分割

* 正規表現ベースで不適切なセグメントを分割
* 分割ルールは外部（dict / yaml）から与える
* 分割のみを行い、統合は考えない

---

### 3. セグメント再統合

* 分割されたセグメントを戦略ベースで再統合
* split と merge は必ず別処理として扱う

---

## やらないこと

* CLI 提供
* 設定ファイル管理
* ログ設定
* 翻訳・校正ロジック

それらはすべて **上位プロジェクトの責務**。

---

## 想定される利用元

* 自前翻訳パイプライン
* 単発スクリプト

どこから呼ばれても
「xliff を安全に変形するだけ」の立場を崩さない。

---

## 注意

このライブラリは **実務前提で設計**されている。
汎用性よりも、

* 壊れない
* 予測可能
* 差分が追える

ことを優先する。

## Known Issues
